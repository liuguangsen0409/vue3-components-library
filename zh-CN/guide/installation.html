安装 ​

环境要求 ​

  • Node.js >= 18
  • Vue >= 3.4
  • Element Plus >= 2.7

使用包管理器 ​

bash
# npm
npm install lgs-ui-vue3 element-plus

# yarn
yarn add lgs-ui-vue3 element-plus

# pnpm
pnpm add lgs-ui-vue3 element-plus

提示

本组件库基于 Element Plus 进行二次封装，Element Plus 是必须的 peer dependency。
