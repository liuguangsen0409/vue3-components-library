## API

LgsFooter 继承了 Element Plus [ElFooter](https://element-plus.org/zh-CN/component/container#footer-api) 的所有属性和插槽。以下列出常用属性，完整列表请参考 Element Plus 文档。

### 属性

| 属性名 | 说明 | 类型     | 默认值 |
| ------ | ---- | -------- | ------ |
| height | 高度 | `string` | —      |

### 插槽

| 插槽名  | 说明     |
| ------- | -------- |
| default | 页脚内容 |
